# Решения по проекта (Markly)

Този файл фиксира решения, взети за проекта, за да не се преразглеждат/обръщат случайно.
Ако нещо тук трябва да се промени — променя се съзнателно и файлът се обновява веднага.

## Java версия

**Java 21.** Не 25. `backend/pom.xml` → `<java.version>21</java.version>`.

## Схема на потребителските имена

И двете роли (учител, ученик) ползват **имейл** като потребителско име. Няма факултетни
номера, няма ЕГН — никъде в активния код (`backend/`, `frontend/`). ЕГН съществува само в
`legacy/` (старата TCP socket версия, необслужвана, не се пипа).

* **Admin** — `admin` (фиксирано потребителско име)
* **Teacher** — трябва да завършва на `@uni-sofia.bg` (валидирано с regex в
  `UserValidationService`)
* **Student** — произволен валиден имейл, без ограничение за домейн

Парола и за двете роли: **поне 5 символа**, без формат-ограничения (не ЕГН, не цифри).

## Демо данни

`SEED_DEMO_DATA=true` при първо стартиране създава:

* 8 учителя: `teachera@uni-sofia.bg` … `teacherh@uni-sofia.bg`
* 20 ученика: `student1@test.com` … `student20@test.com`
* ~400 оценки по 8 предмета

## Пароли

**Всички акаунти (admin, всички учители, всички ученици) използват една и съща парола:
`password12345`.** Няма изключения. Ако се добавя нов акаунт ръчно през admin панела, дай му
същата парола, освен ако изрично не е поискано друго.

## Admin креденшъли

`admin` / `password12345` (виж `SEED_ADMIN_USERNAME` / `SEED_ADMIN_PASSWORD` в `backend/.env`
за реалната стойност, ако някой я е сменил локално).
